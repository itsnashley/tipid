How Tipid builds your plan

Both tools solve the 0/1 knapsack problem with dynamic programming by default. The table has one row per item and one column per peso, from zero up to your budget. Each cell holds the best total value reachable with those items and that much money. Every item is either taken once or skipped. The greedy comparison takes items by best value per peso until the money runs out, which is fast but can miss the best mix. In both tools you can switch (Settings, top right) to the fractional knapsack, which uses the same value-per-peso order but lets the last item be taken partially. It is quick and always at least as good as whole items, but only fits things you can split. The food database holds typical Philippine prices per serving. They are estimates, so adjust them to what you actually pay.
